# Juntos con Ramón

Landing page oficial de la campaña de **Ramón Rodríguez** a la Rectoría de la Universidad Autónoma de Chiriquí, período 2026–2028.

## Estructura

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
    └── images/
        ├── brand/       # Isotipo, casilla 1, logos y favicons
        ├── guidelines/  # Paleta y tipografías autorizadas
        ├── ramon/       # Fotografías oficiales optimizadas
        └── social/      # Imagen Open Graph para compartir
```

## Características

- Sitio estático, rápido y responsive.
- Identidad visual basada en la paleta oficial morada.
- Animaciones 3D y cinemáticas con degradación elegante cuando el usuario prefiere menos movimiento.
- Videos oficiales integrados desde Instagram.
- Propuesta institucional y brochure integrados desde Heyzine.
- SEO básico, Open Graph, favicon, accesibilidad y navegación móvil.
- Contador dinámico al 19 de agosto de 2026.

## Desarrollo local

No requiere compilación. Se puede abrir `index.html` directamente o servir la carpeta con cualquier servidor estático:

```bash
python -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Publicación

Compatible con GitHub Pages, Netlify, Vercel o cualquier hosting de archivos estáticos.
